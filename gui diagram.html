User Flow Map 5 Key Journeys
1

💰 Deposit Funds

User adds money to their wallet via various payment methods

Dashboard → Deposit Enter Amount Select Method Confirm Balance Updated
2

🐷 Create Savings Goal

User sets a financial target with deadline and tracks progress

Dashboard → Savings + New Goal Name + Target Set Deadline Track Progress
3

📊 Set Budget Category

User creates monthly spending limits for different categories

Dashboard → Budget + Add Category Select Category Set Limit Monitor Spending
4

🔄 Setup Recurring Transaction

User automates regular payments or income streams

Dashboard → Recurring + Add Recurring Name + Amount Frequency Start Date Auto-Process
5

🛡️ Emergency Fund Management

User builds and accesses their financial safety net

Dashboard → Emergency Add Funds Track Progress Withdraw (Emergency) View History
